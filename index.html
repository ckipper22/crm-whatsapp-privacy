Politica de Privacidade — CRM para WhatsApp

Ultima atualizacao: Setembro 2026

1. Dados coletados

Esta extensao coleta apenas os dados estritamente necessarios para seu funcionamento:

  • Email da conta Google: Utilizado exclusivamente para autenticacao via OAuth2 junto a API backend. Nao e armazenado permanentemente.
  • Telefone e nome de clientes: Consultados na API da farmacia para identificacao do atendimento. Ficam armazenados localmente no navegador (chrome.storage) apenas durante a sessao de uso.

2. Uso dos dados

  • O email e usado apenas para verificar se o usuario esta autorizado a usar a extensao.
  • Os dados de clientes sao usados apenas para exibir informacoes relevantes ao atendimento no WhatsApp.
  • Nenhum dado e compartilhado com terceiros.
  • Nenhum dado e usado para fins de publicidade, analytics ou rastreamento.

3. Armazenamento e seguranca

  • Todos os dados ficam armazenados localmente no navegador do usuario.
  • Nenhum dado e enviado para servidores de terceiros além da API oficial da extensao.
  • A autenticacao e feita via Google OAuth2, que nao fornece a extensao acesso a senha do usuario.

4. Retencao de dados

  • O token de sessao e armazenado em memoria e descartado ao fechar o navegador.
  • Os dados de clientes e configuracoes sao mantidos localmente enquanto o usuario nao desinstalar a extensao ou limpar os dados do navegador.

5. Direitos do usuario

  • O usuario pode revogar o acesso da extensao a sua conta Google a qualquer momento nas configuracoes do Chrome.
  • O usuario pode desinstalar a extensao a qualquer momento, o que remove todos os dados locais.
